## Binsight Machine Learning

Binsight ML is a program that uses machine learning on an UNO R3 microcontoller, XAIO esp32S3 sense camera, and moving parts to create a smart trash bin.

The smart trashbin allows you to hold an item up to the camera. The camera will classify the item at the edge, the classification will be fed into your state/county recycling legislation, the correct lid will open up.
